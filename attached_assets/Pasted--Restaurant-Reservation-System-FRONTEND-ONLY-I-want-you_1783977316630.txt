# Restaurant Reservation System - FRONTEND ONLY

I want you to build **ONLY the frontend** of a modern restaurant reservation website.

**This frontend will NOT be deployed from Replit.**

It will later be copied into another project where Claude Code will build the backend and connect everything together. Because of that, **DO NOT build any backend whatsoever.**

## IMPORTANT REQUIREMENTS

* Frontend ONLY.
* Do NOT create Express, Node.js backend, databases, API routes, authentication logic, server actions, or server-side code.
* Do NOT use Replit authentication.
* Do NOT use Firebase, Supabase, Clerk, Auth0, or any backend service.
* Do NOT create serverless functions.
* Do NOT create deployment configuration specific to Replit.

The project should be a clean, standard **React + Vite + Tailwind CSS** application that can easily be copied into another project and deployed on **Render**.

Everything should currently use:

* Mock data
* Placeholder JSON
* Dummy API functions
* Local component state

The project should have clean folders such as:

* src/components
* src/pages
* src/layouts
* src/hooks
* src/services (mock services only)
* src/assets

Keep components reusable and well organized.

## Reservation Flow

Create a beautiful multi-step reservation experience.

### Step 1

Customer Account

Fields:

* Full Name
* Phone Number
* Password

Include a note that an account is only required so customers can later access their reservation and QR code.

---

### Step 2

Reservation Details

Fields:

* Date
* Time
* Number of Guests
* Special Requests (optional)

---

### Step 3

Payment

Allow two choices.

Option 1:

Pay with CliQ

Display:

* Restaurant CliQ Alias
* Restaurant Phone Number
* Copy Button

Use placeholder values.

After payment show a button:

"I've Sent the Payment"

Display a message explaining that the restaurant will verify the payment.

---

Option 2

Pay Upon Arrival

Show a short explanation.

---

### Step 4

Confirmation

Show:

* Reservation Status
* QR Code Placeholder
* Confirmation Number
* Date
* Time
* Guests
* Payment Method
* Payment Status

The QR should simply be a placeholder image.

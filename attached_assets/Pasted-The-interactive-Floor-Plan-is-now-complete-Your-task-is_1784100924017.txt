4. TABLE SELECTION MODE
==================================================

While choosing a table:

AVAILABLE TABLES:

- Should be visually highlighted.
- Should be clickable.
- Should have a clear "Select Table" hover state.

UNAVAILABLE TABLES:

- Waiting For Guests
- Occupied
- Special Guest
- Out Of Service

These must be visually dimmed and must NOT be selectable.

Do not allow the waiter to accidentally assign an unavailable table.

8. OCCUPIED TABLE WORKFLOW
==================================================

When an occupied table is clicked, show:

- Customer Name
- Guest Count
- Time Seated

Primary action:

After confirmation:

- Keep the completed reservation in reservation history.

==================================================
9. CHANGE / MOVE TABLE
==================================================

For a table that is:

- Waiting For Guests
OR
- Occupied

include:

CHANGE TABLE / MOVE TABLE

When clicked:

- Keep the current reservation selected.
- Enter Table Selection Mode.
- Highlight available tables.
- Allow switching between floors.
- Do not release the old table until the new table assignment is confirmed.

After confirmation:

- Release the old table.
- Assign the new table.
- Preserve the reservation status.

If the guests were already seated, the new table becomes Occupied.

If they were Waiting For Guests, the new table becomes Waiting For Guests.
